# Security Policy

## Reporting a vulnerability

If you discover a security issue (for example in the FastAPI service or the web
app), please report it privately rather than opening a public issue:

- Use GitHub's **"Report a vulnerability"** (Security → Advisories) on this
  repository, or contact the maintainer directly.

Please include steps to reproduce and the affected component. We'll acknowledge
receipt and work on a fix as soon as reasonably possible.

## Scope

This is an educational project on public data. It stores no personal data and is
not a clinical system. The most relevant surfaces are the prediction API
(`api/`) and the website (`web/`).
